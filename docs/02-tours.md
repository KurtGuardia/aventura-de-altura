## Tour 2 · Toro Toro (1, 2 o 3 días)

| Campo | Valor |
|---|---|
| Tipo | Naturaleza / paleontología / espeleología |
| Duración | Variantes de 1, 2 y 3 días |
| Distancia | ~3,5 h desde Cochabamba (vía Tarata, Anzaldo, La Viña y Tarapaya) |
| Hospedaje | Hotel Villa Etelvina o Cabañas de Umajalanta, con baño privado |
| Dificultad | **No especificada** (incluye caverna y descenso al cañón) |

### Atractivos (texto largo disponible en Canva; resumir para la web)

- **Huellas de dinosaurios** (cerro Wayllas): Cretácico, ~130 millones de años. Es la región con mayor representación paleontológica de Bolivia.
- **Caverna de Umajalanta**: la más profunda de Bolivia; pórtico de 40 × 30 m; a 10 km del pueblo.
- **El Vergel**: cañón de ~150 m de profundidad, pozas naturales y cascada sobre musgo.
- **Ciudad de Itas**: formaciones rocosas tipo ciudadela, con pinturas rupestres; a 25 km.
- **Pueblo de Toro Toro**: historia que se remonta a 1592.

**Día 1**

- 13:00 Almuerzo.
- 14:30 Salida hacia la Ciudad de Itas; 15:00 visita (~3 h).
- 16:30 Refrigerio.
- 18:00 Regreso al hotel.
- 19:30 Cena.
- 20:30 Fogata.

**Día 2**
- 07:30 Desayuno y check-out.
- 08:30 Circuito del Vergel: miradores, descenso al cañón, cascadas y pozas.
- 12:30 Regreso al pueblo.
- 13:30 Almuerzo.

## Modelo de datos propuesto (esquema Sanity `tour`)

Derivado de los tres tours. Cubre todas las variantes sin campos ad hoc.

```ts
tour {
  title: localeString            // ES/EN
  slug: slug
  category: 'trekking' | 'naturaleza' | 'cultura' | 'alta-montana'
  shortDescription: localeText   // para la tarjeta
  description: localeBlock       // para el detalle
  coverImage: image (con alt)
  gallery: image[]
  difficulty: 'baja' | 'media' | 'alta'
  altitude?: number              // msnm
  departureCity: string          // "Cochabamba"
  featured: boolean
  order: number
  highlights?: { title, text, image }[]   // atractivos (Toro Toro)
  variants: {                    // 1 variante en Tunari; 3 en Toro Toro
    label: localeString          // "1 día", "2 días"…
    durationDays: number
    nights: number
    lodging?: string
    itinerary: { day: number, items: { time?: string, text: localeString }[] }[]
    pricing: { minPax: number, maxPax?: number, pricePerPerson: number }[]  // USD
  }[]
  includes: localeString[]
  excludes: localeString[]
  requirements?: localeString[]  // condición física, aclimatación, equipo
  notes?: localeText
}
```

**Decisión implícita:** los precios se guardan por tramo de grupo y la tarjeta muestra "desde USD X", calculado como el mínimo del tramo de 5 o más personas.
